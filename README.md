# Madalena Leão — portfolio

Dedicated static deployment of the client-approved portfolio for madsleao.com. Original client typography, colours and imagery; dependency-free motion and native scrolling.

Routes: `/`, `/projects/`, `/wpp-open/`, `/ethereal-nexus/`, `/europcar/`, `/one-shop/`.

The approved source was prepared from patch-flowstudio/Patch-Flow-Studios commit `872eee256ac69b6ad5fc8580b6a8d17a91e3169b`, with root-domain canonical URLs, an indexable sitemap, and a projects index preserving the existing URL. The separate studio and portfolio demo stay in the original repository.

GitHub Pages publishes the root of `main`. Local preview: `python -m http.server 4173 --bind 127.0.0.1` from this directory. No installation or build is required. Preserve the `CNAME` file once the custom domain is configured.

Portfolio content and media belong to the client. One.Shop keeps the original public disclosure limits; no confidential product designs or invented impact metrics are added.
